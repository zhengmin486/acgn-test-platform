说明

Bangumi 没有「随机条目」官方接口，随机探测 ID 会产生大量 404 并触发限流。 本功能改用随机偏移翻排行榜页：先读首页拿到榜单总量，再在全部深度里随机抽偏移取页， 一页就是几十个保证有效的候选；选中之前先在本地跳过已入库作品和 NSFW 条目， 最后复用标准导入流程写入作品、标签、作者/公司关系与封面。

  • 抓取条数 {{ count_max }} 以内可调，默认 {{ count }}；条数多时会翻多页混开批内多样性；
  • 单次最多翻 10 页排行榜，候选不足时按实际可得数量导入；
  • 已存在的作品按 bangumi_id 提前跳过，不覆盖本地数据；
  • 需要可访问 Bangumi 的网络（默认直连，可用 BANGUMI_PROXY 配置代理）。
